# Standards: where code lives

For every project, in any language. Language and stack skills add to this,
with the layout each uses. Where this project's own code or instructions
differ, follow the project.

- Put new code in the layout the language or stack skill gives. Don't move
  existing code into it unless asked.
- Put shared code in the folder closest to everything that uses it. Code one
  part uses stays with that part.
- When a second part starts using something, move it up to the level that
  covers both. Don't import from another part's own folder.
- Don't create empty or placeholder files, screens, or folders. Add each when
  it's needed.
